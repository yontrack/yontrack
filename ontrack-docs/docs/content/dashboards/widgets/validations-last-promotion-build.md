# Validations of last promoted build

**Key:** `home/ValidationsLastPromotionBuild`

Shows the validation results for the most recent build promoted to a given promotion level on a branch.

## Configuration

| Field | Type | Description |
|-------|------|-------------|
| `title` | string | Widget header label. |
| `project` | string | Project name. |
| `branch` | string | Branch name. |
| `promotion` | string | Promotion level name. |
| `validations` | string[] | Validation stamps to display. |
